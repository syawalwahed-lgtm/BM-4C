## Cara guna
1. Buka `index.html`.
2. Masukkan nama murid.
3. Tekan Mula Permainan.
4. Gunakan butang Bunyi untuk hidup/matikan audio.
5. Jawapan betul memberikan maklum balas suara dan bintang.
6. Jawapan salah boleh dicuba semula.
7. Di akhir permainan, keputusan dipaparkan.

## GitHub Pages
Muat naik `index.html` ke satu repository GitHub, kemudian pilih:
Settings → Pages → Deploy from a branch → `main` → `/root` → Save.

Selepas GitHub Pages selesai diterbitkan, pautan akan berbentuk:
`https://NAMA-ANDA.github.io/NAMA-REPOSITORY/`
